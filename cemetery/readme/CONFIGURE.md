# Define product to use for cemetery logistic moves

1.- Go to Cemetery > Configuration > Settings

2.- Define the product to use for logistic moves

# Create cemeteries

1.- Go to Cemetery > Configuration > Cemeteries

2.- Create cemeteries

# Define storage categories

1.- Go to Inventory > Configuration > Storage Categories

2.- Create a new category. Define the max capacity for the configured beneficiary product

# Create locations

1.- Go to Cemetery > Configuration > Locations

2.- Create locations

3.- Assign storage category
