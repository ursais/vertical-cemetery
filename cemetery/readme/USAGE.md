# Beneficiaries' management

1.- Go to Master Data > Beneficiaries

2.- Create a new beneficiary or select a beneficiary record

3.- Assign the Current Location for the beneficiary. This will create the transfer

4.- If the beneficiary being transferred to a location would exceed that location's capacity as defined by its storage category, an error will pop up

# Transform a contact into any cemetery record type

1.- Create a Contact record (res.partner)

2.- Click on the Actions menu (the cog) > Convert to Cemetery Record

3.- Select the type of record to create from the Wizard
